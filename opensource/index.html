Open Source Project

Spy-Search

Co-developed Spy-Search, an open-source, modular multimodal research assistant and LLM search engine, designed as a fast, low-cost alternative to commercial AI search tools such as Perplexity. It combines web retrieval, multimodal document understanding, and LLM-based reasoning to answer questions and generate long-form research reports from up-to-date sources.

  • Multimodal retrieval and question answering over web pages and documents, not only plain text
  • Modular agent pipeline built with LangChain: retrieval, document understanding, and LLM synthesis into answers or reports
  • Works with cloud LLM APIs (OpenAI, Claude, Grok, etc.) or fully local models through Ollama
  • Web front end and API back end, deployable with Docker Compose
